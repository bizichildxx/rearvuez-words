## Web / VR app

The interactive site (TanStack Start + React + Three.js / WebXR VR room) was built in **Grok App Builder**. To publish the live app:

1. Open that App Builder project again
2. Use the builder **Publish** control so it deploys to your `*.grok.me` URL

This chat session only has the media pack, not the full app source tree.
